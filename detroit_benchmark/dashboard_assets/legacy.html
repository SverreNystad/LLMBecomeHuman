03 / METHODOLOGY

Designed for auditable research.

What the dashboard records — and what the results do not establish.

01

Input visibility

Each decision can reveal the exact model-facing scene, available options, world flags, retrieved earlier scenes, and the full decision history passed to the model.

02

Public justification

The model provides a short, recorded rationale for each choice. This is a stated justification, not an exposure of private internal chain-of-thought.

03

Branch-aware comparison

Identical nodes with identical visit numbers can be compared directly. Choices on separate routes are marked path-exclusive rather than called disagreements.

04

Ground truth matters

The dialogue importer does not establish all original game consequences. Exploratory transcripts are prominently marked; verified game-state rules are required for credible outcome rankings.

05

Live progress

This service reads existing experiment.json, events.jsonl, checkpoint.json, and summary.json artifacts. It never invokes a model or changes a saved run.

06

Privacy

Run logs may contain copyrighted dialogue and model inputs. The server binds to 127.0.0.1 by default and has no authentication for public deployments.
